\begin{abstract}
This project aims to develop a humanoid robot capable of basic controlled limb function and human-robot interaction through computer vision. A key challenge in developing human-robot interaction is allowing robots to respond to and replicate human movements rather than relying solely on predefined movements. The initial phase of the project will rely solely on an Arduino to control all robot functions. An Arduino will control servo motors, which allow the robot to execute predefined arm movements. Once the Arduino-powered movement is reliable, a Raspberry Pi and integrated camera will be used to mimic arm motions. By utilizing pose estimation algorithms, the robot will analyze human positions, translate these movements into commands for the Arduino, and allow the robot to replicate the human’s motion. Overall, this project will combine the principles of design, electronics, and artificial intelligence to show how visual models can be integrated with computer systems to create a humanoid system.
\end{abstract}

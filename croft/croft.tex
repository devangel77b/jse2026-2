\begin{abstract}
AI agents based on large language models (LLMs) can solve problems by reasoning, call external functions and perform tasks with minimal human intervention. However, one individual agent may struggle to solve problems involving multiple conflicting constraints, substantial amounts of specific knowledge, and information that is supposed to stay confidential. There are two emerging standards which partially tackle this problem: Model Context Protocol (MCP), providing the basis for all agents to interact with external tools and data, and Agent Skills, packaging reusable instructions, references and scripts used by an agent if required to perform a certain task. This project introduces a hierarchical multi-agent system where a master agent decomposes complex tasks into simpler sub-tasks, assigns sub-tasks to specialized sub-agents, mediates between conflicting proposals of sub-agents, and requests re-processing of results that fail verification. The implementation will use Python with Agno agent framework and FastAPI server, connecting to both publicly available and customized MCP servers, and extending them with original and validated third party Agent Skills. A browser interface will allow monitoring in real time each individual agent's call of tools and skills, and a database will maintain session persistence. The browser interface will stream the activities of all the tools and skills for the agents in real time, while a database will make sessions persistent.
\end{abstract}
